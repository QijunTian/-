# 摸鱼锅

浏览器可运行的解压小游戏：**把上班压力甩进锅里炖掉，看桌面变干净。**

> 学爆款的是解压心理（即时反馈、混乱变秩序、安全宣泄），不是抄三消/堆叠模式。见 `docs/project/02-解压重做-学原因不抄玩法.md`。

## 怎么跑

```bash
cd game
npm install
npm test
npm run dev
```

## 操作

1. 拖桌面上的压力团，甩进下方锅里  
2. 点锅加速炖化  
3. 炖熟爆发 → 桌面更干净 → 清完下班  

## 验证

- `npm test`：甩入、炖化爆发、自动慢炖  
- `npm run build && npm run preview` 后可浏览器冒烟
