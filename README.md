# 摸鱼锅

浏览器可运行的超轻消除小游戏原型：三消堆叠 + 颠锅 + 职场情绪文案 + 模拟激励广告。

## 怎么跑

```bash
cd game
npm install
npm test
npm run dev
# 浏览器打开终端提示的本地地址
```

生产预览：

```bash
cd game
npm run build
npm run preview
```
