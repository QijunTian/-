# 《摸鱼锅》解压向重做：学原因，不抄玩法

更新：2026-07-21

## 1. 爆款为什么解压（学这个）

| 心理机制 | 玩家体感 | 我们怎么用（不抄模式） |
|----------|----------|------------------------|
| 即时正反馈 | 每一下都有变化 | 甩出去必有水花/音效，炖化必缩小 |
| 混乱→秩序 | 脏变干净 | 桌面从堆满压力→清空发光 |
| 安全宣泄 | 敢砸、敢扔，无后果愧疚 | 把老板/钉钉甩进锅里炖掉 |
| 可控结果 | 少靠纯折磨RNG | 甩中锅是技巧，炖化是确定进度 |
| 低认知负荷 | 单指、5秒上手 | 拖甩 + 点锅加速，无槽位规则讲解 |
| 短闭环 | 几分钟有完成感 | 清完一桌=一班下班 |

**刻意不做：**三消进槽、堆叠遮挡点选、羊/鹅式第二关地狱（那是“执念上头”，不是“解压”主路径）。

## 2. 新核心循环（原创）

```
桌面冒出压力团 → 手指甩进锅 → 锅里炖化缩小
→ 攒够火候爆发清锅 → 桌面更干净 → 下一波
→ 一桌清空 = 下班通关
```

一句话：**把上班压力扔进锅里炖掉，看桌面从乱变净。**

## 3. 验收（解压向）

1. 第一次甩进锅，必须在0.3秒内有水花+音效  
2. 炖化过程肉眼可见（变小/冒泡）  
3. 爆发清锅后，桌面明显更空、有闪光  
4. 陌生人无教程10秒内完成至少1次“甩入+炖化”  
5. 不再出现“餐盘7格三消”规则
