# 调研结论与项目目标

更新：2026-07-17

## 1. 市场调研结论（摘要）

| 观察 | 依据 | 对我们的含义 |
|------|------|----------------|
| 爆款主核仍是「消除即时爽感」 | 《羊了个羊》《抓大鹅》长线在榜 | MVP只做单核消除，不堆养成 |
| 验证玩法是「三消 + 堆叠遮挡 + 槽位」 | 羊：点进槽，三相同消，槽满失败；鹅：3D堆叠+颠锅 | **修正原GDD二消为三消**（市场已验证，手感更稳） |
| “第一关幼儿园、第二关地狱”是传播引擎 | 多篇复盘一致 | 必须做两关难度差，不能只有一关 |
| 失败要可截图、可发短视频 | 抖音破圈靠节目效果 | 失败大字文案是一等公民功能 |
| 广告点在卡关续命，不在开局强插 | IAA共性 | Web原型用「观看模拟广告3秒」真实走完流程，禁止一键白送且无等待 |
| 平台侧暂无抖音/微信凭证 | 环境事实 | 先交付**浏览器可运行**竖屏原型，规则与小游戏一致，便于后续迁移 |

## 2. 明确目标（可验证）

### 北极星

做出一款浏览器里能打开就玩的《摸鱼锅》，规则真实完整，陌生人30秒内能过教学关。

### 验收清单（必须全部真实实现，禁止假跳过）

1. 场上物体存在堆叠遮挡：**被压住的点不到**（点击无效并有反馈）  
2. 点击可点物体进入底部槽；**3个相同自动消除**  
3. 槽位满且无法形成三消 → **失败**，展示随机失败文案  
4. 场上清空 → **通关**  
5. **颠锅**：消耗次数，真实改变遮挡关系（露出下层），次数用尽可「看广告」加次  
6. **复活**：失败后「看广告」倒计时结束后清空槽或撤销，可继续玩  
7. **试锅关 + 今日挑战关**两套真实配表参数  
8. `npm install && npm run dev` 后本地可玩；另提供 `npm run build` 与预览  

### 非目标（本阶段不做）

- 真实抖音/微信登录、支付、分享到会话  
- 联网排行榜、多人对战、养成树  
- 精美3D引擎资产（用Canvas 2.5D伪透视即可）

## 3. 成功标准（测试时对照）

| 项 | 标准 |
|----|------|
| 启动 | 开发服打开首页无白屏、无控制台致命报错 |
| 教学关 | 新手无说明也能在约1分钟内打过 |
| 遮挡 | 手动点被压物体，槽位不增加 |
| 三消 | 槽内凑齐3个同名，立即消失且场上计数减少 |
| 颠锅 | 点击后至少1个原先不可点变为可点，或层级关系可见变化 |
| 广告流 | 复活/加颠锅必须出现≥2.5秒等待，结束后才给奖励 |
