# 《摸鱼锅》可开发玩法文档（MVP）

> 定位：抖音/微信小游戏 · 超轻IAA · 单核堆叠消除 · 职场情绪外壳  
> 目标：3秒看懂、30秒过首关、失败可传播、单局60–180秒  
> 版本：v0.2 · 2026-07-17  
> 实现：`game/` 浏览器可运行原型（Vite + Canvas）

---

## 1. 一句话产品

**在一口“摸鱼锅”里颠出并消除同类职场符号，在锅满之前清场；差一点通关的不甘，加上离谱失败文案，驱动“再来一局”和短视频分享。**

成熟手感（3D堆叠/颠锅）× 强情绪题材（打工人共情）× 节目效果失败。

---

## 2. 玩家是谁、抓什么心理

| 人群 | 场景 | 核心情绪 |
|------|------|----------|
| 20–35岁打工人 | 通勤、午休、睡前摸鱼 | 被KPI支配的无力 + 想掌控一点什么 |
| 轻度休闲玩家 | 刷抖音点开即玩 | 解压、收集、社交谈资 |

打中的心理开关（按优先级）：

1. **即时掌控**：点一下就消、颠一下就露，反馈≤0.1秒  
2. **差一点就赢**：首关必过，挑战关“差一口”  
3. **整理癖爽感**：乱锅变整齐的强迫症满足  
4. **社交货币**：失败文案好笑、通关出限定“锅贴”可炫耀  
5. **损失厌恶**：每日限定挑战次数 / 今日锅贴未收集完

## 3. 核心循环（必须极简）

```
进锅 → 看堆叠 → 点选同类消除（或颠锅露出）→ 腾出空间
  → 新物掉入 → 接近锅沿危机 → 清场通关 / 溢出失败
  → 结算（文案+收集）→ 再来一局 / 看广告续命
```

### 3.1 基础规则（玩家无需读说明）

1. 锅内是堆叠的“职场符号”（色块+短词）。  
2. 点选物体进入“餐盘槽”（槽位上限**7**）。  
3. 槽位凑齐**3个相同**即消除；槽满且无法消除则失败。  
4. 被压住的物体点不到；可点**颠锅**打乱并抬起下层（每局有限次，或看广告加次）。  
5. 场上清空且槽清空即通关。  

> v0.2 修正：原“二消/槽位4”改为市场已验证的“三消/槽位7”，见 `docs/project/00-调研结论与目标.md`。

### 3.2 单局时长预算

| 阶段 | 时长 | 玩家感受 |
|------|------|----------|
| 开局识别 | 0–5秒 | “哦就是消东西” |
| 顺畅消除 | 5–40秒 | 爽、有掌控 |
| 空间吃紧 | 40–90秒 | 紧张、开始颠锅 |
| 终盘博弈 | 90–150秒 | 差一口 / 爆锅 |
| 结算 | 3–5秒 | 文案梗 + 收集 |

| ID | 显示名 | 情绪标签 | 备注 |
|----|--------|----------|------|
| 01 | 钉钉 | 焦虑 | 红点闪一下（轻动效） |
| 02 | KPI | 压力 | 数字样式 |
| 03 | 周报 | 烦 | 纸张 |
| 04 | 会议 | 耗尽 | 日历 |
| 05 | 老板 | 恐惧 | 墨镜剪影 |
| 06 | 咖啡 | 续命 | 正面道具感 |
| 07 | 外卖 | 慰藉 | 正面 |
| 08 | 摸鱼 | 爽 | 稀有一点 |
| 09 | 加班 | 黑 | 月亮 |
| 10 | 绩效 | 赌 | 表格 |

后续可按节日换皮（年会锅、双十一锅），不改规则只换表。

### 4.2 视觉基调

- 一只居中大锅（俯视略斜45°），暖黄汤底 + 轻微冒泡。  
- 物体Q版图标，描边清晰，适合竖屏短视频录屏。  
- **禁止**复杂UI：顶部只留关卡名+颠锅次数；底部餐盘槽4格。  
- 失败时锅沸腾溢出，全屏大字文案（见第8节）。

### 4.3 音频（最小集）

- 消除：清脆“叮”  
- 颠锅：金属晃动  
- 危机：锅沿水位警报轻嗡  
- 失败：夸张“咕咚”+短语音（可关）

## 5. 关卡与参数（可直接配表）

### 5.1 关卡结构

每日内容固定为**2关**：

| 关卡 | 名称 | 目标 | 设计意图 |
|------|------|------|----------|
| 1 | 试锅（摸鱼局） | 必过教学 | 建立掌控感、降低流失 |
| 2 | 今日挑战 | 难、可反复重试 | “差一点”驱动分享与广告 |

可选：通关后解锁“无尽炖”（无尽模式，次日刷新主题），用于留存，不做首周重点。

### 5.2 难度参数表（建议初始值，上线后按数据微调）

| 参数 | 试锅 | 今日挑战 | 说明 |
|------|------|----------|------|
| 物体种类数 | 4 | 7–8 | 种类越多越难 |
| 场上初始物体数 | 18 | 36–42 | |
| 每对物体个数 | 偶数，各4–6 | 各4–8 | 必须可解优先 |
| 餐盘槽位 | 4 | 4 | 固定 |
| 被压住比例 | 30% | 55%–65% | 挑战关更“看得见点不到” |
| 免费颠锅次数 | 3 | 1 | 挑战关逼广告/分享 |
| 暗改：连续失败3次 | — | 减少2个障碍物或+1颠锅 | “可控随机”，别让人永久非 |
| 目标通关率（挑战关） | — | 首日约8%–15% | 太高无话题，太低留存崩 |

### 5.3 “差一点”生成规则（关键）

挑战关生成器约束：

1. **可解性**：种子关卡保证存在至少一条合法消除序列（或运行时校验）。  
2. **残局感**：最后8–12个物体时，故意提高“顶层遮挡”与“槽位冲突”概率，制造差一对爆锅。  
3. **伪随机保底**：每局至少刷出1对“摸鱼”或“咖啡”在中后段，给翻盘希望。  
4. **失败安抚**：连败≥3，下一局自动启用“微降遮挡”或“开局多1次颠锅”，UI不提示。

### 5.4 每日刷新

- 每日0点刷新：挑战关种子、锅皮肤小变化、可收集“锅贴”。  
- 每日挑战次数展示为“今日火候×3”（可看广告+1），制造回访钩子，但**不要**硬墙到玩不了——第4次起必须可用广告续。

## 6. 操作系统与交互

### 6.1 操作

| 操作 | 方式 | 备注 |
|------|------|------|
| 选择物体 | 单击 | 被压住则抖动拒绝 |
| 取消选择 | 点餐盘已选或点空白 | |
| 颠锅 | 按钮 / 陀螺仪摇晃（可设置关闭） | 抖音素材核心看点 |
| 暂停 | 角标 | 仅设置与音量 |

### 6.2 新手引导（≤5秒，可跳过）

1. 高亮一个可点物体：“点同类放进餐盘”  
2. 高亮颠锅按钮一次：“晃一晃露出下面”  
3. 结束，不再弹窗

### 6.3 失败 / 复活流程

```
溢出或槽满 → 播失败动画 + 文案
  → 主按钮：看广告复活（清空餐盘 or +2颠锅 or 撤销最近3步，三选一随机一种，避免数值膨胀）
  → 次按钮：分享复活（每日限1–2次）
  → 弱按钮：重开 / 回首页
```

复活后给**短保护**：2秒内不掉新物（若有掉落逻辑）或短暂高亮一对可消目标。

## 7. 收集与轻度养成（不加复杂系统）

只做一层收集，禁止养成树/装备栏。

### 7.1 锅贴（每日1张主题）

- 通关挑战关获得今日锅贴（如“周一尸”“甩锅冠军”）。  
- 图鉴进度条：集齐7张周主题 → 解锁锅皮肤。  
- 分享卡片默认带今日锅贴，便于传播。

### 7.2 局内仅有的“策略选择”

无养成。唯一变数是颠锅时机与消除顺序——这就是策略深度，够用。

## 8. 文案与节目效果（传播弹药）

### 8.1 失败大字文案库（MVP备30条，轮换）

示例：

- “你的周报比锅先糊了”  
- “老板隔空点了个赞（嘲讽）”  
- “差一对就自由，自由取消了”  
- “钉钉：检测到你还活着”  
- “这口锅比你绩效还满”  
- “同事已经在第二关合影了”  
- “系统提示：建议明天再摸”  
- “房租说：再来一把？”  

规则：失败文案**必须**支持截图传播；字号大、对比强、可配锅贴纸表情。

### 8.2 通关文案

- “今日摸鱼合格，KPI暂时假死”  
- “你把加班炖化了”  
- 展示获得的锅贴大图 + “分享到群里装一下”

### 8.3 危机旁白（水位到80%时飘字）

- “锅要开了……”  
- “还敢点开会？”

## 9. 广告点位（IAA优先）

原则：**打断心流的广告要换明确收益；结算页可插屏；禁止开局强制。**

| 点位 | 类型 | 触发 | 收益 | 频率上限 |
|------|------|------|------|----------|
| 复活 | 激励视频 | 失败弹窗主按钮 | 续命一种 | 单局≤2 |
| 加颠锅 | 激励视频 | 颠锅次数为0点按钮 | +2次 | 单局≤2 |
| 提示一对 | 激励视频 | 主动点“提示” | 高亮一对可消 | 单局≤1 |
| 双倍锅贴 | 激励视频 | 通关结算 | 额外1张随机锅贴 | 每日≤3 |
| 加挑战次数 | 激励视频 | 次数用尽 | +1次挑战 | 每日≤5 |
| 插屏 | 插屏 | 主动回首页/重开时 | — | 冷却≥60秒 |
| Banner | 可选 | 结算页底部 | — | MVP可关 |

**首周不接内购。** 若后续接IAP，仅卖“去广告月卡”和“锅皮肤礼包”，不动数值。

## 10. 社交裂变（只留1个主钩子）

主钩子：**失败/通关分享卡**

- 卡片含：锅截图 + 文案 + 今日锅贴 + 小程序/抖音路径。  
- 好友点开直达“今日挑战”（可旁观残局：展示分享者失败时的锅，一键“帮他清一对”仅表情互动，不做强依赖）。  
- 地域榜（省/市通关人数）周更一次，弱展示，防过度攀比反感。

不做：强制邀请才能玩、多层返利。

## 12. MVP范围与非目标

### 12.1 做（2周可出可玩包的理想切片）

- 锅场景 + 12种物体 + 堆叠点击消除 + 颠锅  
- 试锅 + 今日挑战（配表）  
- 失败文案库≥30 + 锅贴图鉴基础  
- 激励视频点位：复活、加颠锅、加次数  
- 分享卡  
- 基础埋点（见下）

### 12.2 不做（刻意砍掉）

- 多人对战、公会、赛季通行证  
- 复杂养成、抽卡英雄、剧情章节  
- 精美3D角色、开放世界锅  
- 开玉石/强赌博数值（合规与长线风险）

## 13. 埋点与验收标准

### 13.1 关键埋点

`session_start` / `level_start` / `level_clear` / `level_fail` / `revive_click` / `revive_success` / `shake_use` / `ad_reward_*` / `share_click` / `share_success` / `sticker_unlock` / `return_d1`

### 13.2 验收门槛（内测→软上线）

| 指标 | 目标 |
|------|------|
| 无引导30秒完成试锅 | ≥85%新用户 |
| 试锅→挑战关进入率 | ≥70% |
| 挑战关失败后“再来/复活”点击率 | ≥40% |
| 激励视频完播率 | ≥70% |
| 分享点击占失败局比例 | ≥12% |
| 次日留存（软上线） | 先观测，目标摸到≥25%再放量 |

玩法不合格的判据：多数人在试锅卡住，或挑战关首日通关率>30%（太简单无话题）或<3%（纯折磨）。

## 14. 技术实现提示（给程序）

- 引擎：Cocos / Unity 任一；优先团队熟的。  
- 物体用合批Sprite或简单Mesh，阴影可用贴片假阴影。  
- 堆叠用层级+射线检测“是否被遮挡”，不必上完整物理；颠锅可用动画扰动+短暂可点穿透。  
- 关卡用JSON种子：`{ id, types[], counts[], coverRatio, shakeFree, seed }`。  
- 广告与分享抽象成接口，微信/抖音各接一层。
